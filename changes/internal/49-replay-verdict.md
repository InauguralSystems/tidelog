- The replay oracle (`test/replay.sh`) now fails unless both the record and replay runs exit 0, the record run prints a complete digest (`version N` first, `log <hex>` last), and the tape carries at least one `N` record; failures print both exit codes and stderrs. Previously equal stdout was the only verdict, so a `tidelog.eigs` that crashed at line 1, threw mid-digest, or a missing runtime all passed. `test/run.sh` shows replay.sh's failure reason, and `TIDELOG_SKIP_RUNNER_SELFTEST=1` set on a real tree (one holding `tidelog.eigs`) is now a failure rather than a silent skip of the runner self-tests. `test/test_replay_verdict.sh` plants each case (#49; InauguralSystems/hq#58, TL-REPLAY-1).
